# 💌 Төрсөн өдрийн захидал · Birthday Letter

Ультра-анимэйшнтэй, кино шиг, интерактив төрсөн өдрийн захидлын вэбсайт.
An ultra-animated, cinematic, interactive birthday-letter website (letter4u-style).
Бүх текст **монгол кирилл** дээр.

---

## 🇲🇳 Монголоор

### Ажиллуулах (хамгийн чухал)

```bash
npm install      # анх удаа л
npm run dev      # хөгжүүлэлтийн серверийг асаана
```

Дараа нь хөтөч дээр **http://localhost:5173** нээгдэнэ.
Утсан дээрээ үзэхийг хүсвэл терминал дээр гарч ирэх **Network** хаягийг
(жишээ нь `http://192.168.1.178:5173`) ижил Wi-Fi-д холбогдсон утсаараа нээнэ үү.

### Бүх зүйлээ хувийн болгох — зөвхөн нэг файл

`src/config.js` файлыг нээгээд дараахыг солино:

| Юу | Хаана |
|---|---|
| Хүлээн авагчийн нэр | `recipientName` |
| Илгээгчийн нэр | `senderName` |
| Захидлын текст | `letter.greetingTemplate`, `letter.lines`, `letter.signoffTemplate` |
| Зураг + тайлбар | `photos` массив |
| Хөгжим | `audio.music` |

### Өөрийн зургаа тавих

1. Зургуудаа `public/images/` дотор хийнэ (жишээ нь `photo-1.jpg`).
2. `src/config.js` доторх `photos` жагсаалтад файлын нэр, тайлбарыг бичнэ:
   ```js
   { src: '/images/photo-1.jpg', caption: 'Бидний анхны зураг' }
   ```

### Өөрийн хөгжмөө тавих

1. Дуугаа `public/audio/` дотор хийнэ (жишээ нь `bg-music.mp3`).
2. `src/config.js` доторх `audio.music`-г шинэ нэрээр солино.

> Одоогоор түр зуурын дуу/зургийг автоматаар үүсгэсэн (`scripts/` доторх).

### Бэлэн болгох (зочид сервер рүү)

```bash
npm run build    # dist/ хавтас үүснэ
npm run preview  # бэлэн хувилбарыг шалгах
```

`dist/` хавтасны агуулгыг Netlify, Vercel, GitHub Pages зэрэгт байршуулна.

## 🇬🇧 English

### Run it (one command)

```bash
npm install   # first time only
npm run dev   # → http://localhost:5173
```

Open the **Network** URL printed in the terminal on your phone (same Wi-Fi) to
test the mobile experience.

### Customize everything in ONE file

Edit `src/config.js`:

- `recipientName`, `senderName`
- `letter` — greeting, body `lines`, sign-off (Mongolian)
- `photos` — filenames + captions
- `audio.music` — background track

### Swap in your photos

Drop files into `public/images/`, then point `config.photos[*].src` at them
(e.g. `/images/photo-1.jpg`). Images are lazy-loaded. The cake scene uses
`config.cake.photos[*].src` (each with `noteTitle` + `noteMessage`).

**Cake centrepiece image** (`config.cake.cakeImage`): use a **transparent-background
PNG** at `public/images/cake.png`. If your cake photo has a solid backdrop, run
`node scripts/cutout-cake.mjs <yourphoto.png> [tolerance]` to remove it (lower
tolerance = less aggressive; `8` works well for pink backdrops). Set
`cakeImage: ''` to fall back to the built-in CSS cake.

### Swap in your music / sounds

Drop files into `public/audio/` and update the paths in `config.audio`.
Placeholder `.wav` files were generated by `scripts/gen-audio.mjs`; regenerate
with `node scripts/gen-audio.mjs`. Placeholder photos: `node scripts/gen-photos.mjs`.

### Build for production

```bash
npm run build     # outputs static site to dist/
npm run preview   # serve the production build locally
```

Deploy the `dist/` folder to any static host (Netlify, Vercel, GitHub Pages).

## 🎬 Scenes / Үзэгдлүүд

1. **Дугтуй (Envelope)** — click the wax seal; the flap folds open in 3D and the letter slides out.
2. **Захидал (The Letter)** — masked, line-by-line reveal of your message. Button **"🎂 Төрсөн өдрийн бялуу"** opens the cake side-trip; **"Дараах"** continues the main flow.
3. **Дурсамж (Gallery)** — 3D polaroids: tap to flip, swipe / arrows to browse.
4. **Төгсгөл (Finale)** — title, confetti burst, music swell, "Дахин үзэх" to replay.

**Side scene · Төрсөн өдрийн бялуу (Orbiting Photo-Cake)** — reached from the Letter.
Memory-cards orbit a CSS cake in true 3D (drag to spin, with momentum). Click a card →
it comes forward and flips into a handwritten note (photo + message). **"Захидал руу
буцах"** returns to the Letter. Configure via `CONFIG.cake` (photos + `noteTitle` +
`noteMessage`, `orbitSpeed`, `photoCount`).

## 🛠 Tech

Vite · vanilla JS · GSAP (+ScrollTrigger) · Lenis (smooth scroll) · Howler.js (sound)
· CSS 3D transforms. Fonts: Playfair Display + Inter (full Cyrillic support).

## ♿ Accessibility & performance

- Respects `prefers-reduced-motion` (calmer, instant fallbacks).
- Animates only `transform` / `opacity`; particles pause when the tab is hidden.
- Mobile-first, fully responsive; custom cursor disabled on touch.
- Keyboard navigation: `←` / `→` step through scenes, `R` replays; the primary
  action is focused on each scene for keyboard users.
- Haptics on tap and device-tilt parallax on phones (where supported).

## 📁 Structure

```
src/
  config.js          ← edit me!
  main.js            ← bootstraps everything
  core/              ← scene manager, cursor, audio, particles, magnetic, text reveal,
                       gate, motion (ease/haptics), parallax (tilt depth), preloader
  scenes/            ← envelope, letter, gallery, finale, cake (one file each)
  styles/            ← base (tokens), cursor, scenes
public/
  images/  audio/    ← your photos & music
  og-image.png       ← social share card (regen: node scripts/gen-og.mjs)
scripts/             ← asset generators + Playwright screenshot/OG tools
vercel.json          ← static deploy config (Vercel)
```
